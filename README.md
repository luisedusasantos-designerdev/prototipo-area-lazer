# Refúgio Verde — protótipo comercial

Landing page demonstrativa para oferecer uma solução digital a proprietários de áreas de lazer.

## Publicar no GitHub Pages

1. Crie um repositório público no GitHub, por exemplo `prototipo-area-lazer`.
2. Faça upload do arquivo `index.html` (na raiz do repositório) e opcionalmente deste `README.md`.
3. Vá em **Settings > Pages > Build and deployment**.
4. Em **Source**, selecione **Deploy from a branch**. Selecione `main` e pasta `/(root)` e salve.
5. Depois de publicado, o endereço geralmente será `https://SEU-USUARIO.github.io/prototipo-area-lazer/`.

## Personalizar antes de enviar a um lead

- No `index.html`, substitua `SEUEMAIL@exemplo.com` pelo seu e-mail.
- Para usar seu WhatsApp em vez de e-mail, substitua o link `mailto:...` do botão final por `https://wa.me/55DDDNUMERO?text=Ol%C3%A1%2C%20gostaria%20de%20conversar%20sobre%20o%20site`.
- Troque o nome fictício `Refúgio Verde` e as imagens quando for criar uma versão para um proprietário.
- As fotos são ilustrativas, carregadas via URLs externas do Unsplash; é necessário estar conectado à internet para visualizá-las. Antes de um projeto comercial definitivo, confira os direitos e substitua por fotos do próprio espaço.

## Limites desta demonstração

- Calendário interativo com datas fictícias geradas localmente; nenhuma reserva é registrada.
- Painel administrativo meramente visual; sem autenticação ou banco de dados.
- Não há contratos reais nem automação de WhatsApp.
- A versão real precisará de backend, autenticação e regras para impedir reservas conflitantes.
